# Contributing

Thanks for contributing! A few guidelines to make contribution smooth:

- Create a branch named `feature/` or `fix/` (e.g. `feature/add-login`).
- Keep commits small and focused. Use clear messages.
- Run `dotnet format` before committing to keep code style consistent.
- Open a Pull Request against `main` and request a review.
- CI will run on push/PR; fix any failing build checks before merging.

If you want a code style or formatting change, please include an explanation in the PR.
